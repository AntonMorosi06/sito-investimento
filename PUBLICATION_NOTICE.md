# Publication Notice

This repository is a public portfolio and demonstration version of the MicroBot project.

The material shown here is intended to communicate vision, architecture, interface design, simulation concepts, documentation structure, and selected prototype work. It must not be interpreted as a complete release of the private technical implementation.

## Prototype and validation status

Unless a section explicitly includes hardware logs, measurements, test evidence, or validation reports, technical values shown in the public website should be treated as one of the following:

- design targets;
- simulated dashboard values;
- conceptual interface values;
- planned prototype specifications;
- non-final engineering assumptions.

Examples include values such as frame rate, latency, positioning precision, number of connected bots, cost per bot, battery duration, communication performance, magnetic docking capability, and terminal status messages.

## Public boundary

The public repository should not include:

- complete firmware intended for physical deployment;
- final CAD files;
- complete electrical schematics;
- complete BOM for immediate replication;
- private business plans;
- investor strategy documents;
- proprietary algorithms;
- unpublished formulas or protocols intended to remain confidential;
- personal documents or certificates with sensitive data.
