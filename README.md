# Sito Investimento MicroBot

Sito pubblico di presentazione e investimento per MicroBot.

## Contenuto

- `index.html` mantiene il sito dimostrativo finale MicroBot FIXED 4.
- `dashboard/` integra il dashboard operativo MicroBot Labs.
- `docs/` include documentazione tecnica, business, BOM, roadmap ed evidenze.

## Note di pubblicazione

Il sito e' statico e puo' essere servito direttamente da GitHub Pages.
La demo biometrica mantiene il flusso originale, ma include anche un accesso demo senza camera per rendere il sito visitabile da investitori, telefono e browser pubblici.
