# MicroBot Labs — Roadmap

## Phase 0.1 — Public Foundation

The first phase creates the public foundation of MicroBot Labs.

The goal is to make the project understandable before making it large. This includes a clean README, a project overview, an architecture overview, a first roadmap, a one-page pitch, and a basic explanation of the first prototype.

Expected outputs:

- Public repository structure.
- README.md.
- Project overview.
- Architecture overview.
- Prototype v0.1 description.
- One-page pitch.
- Short spoken pitch.
- Basic license and changelog.

## Phase 0.2 — ESP32 Master-Node Communication

The second phase focuses on validating communication between a computer, a master ESP32, and one or more nodes.

Expected outputs:

- Master ESP32 firmware.
- Basic node firmware.
- Serial command examples.
- Basic telemetry packet.
- Node status response.
- Communication test log.

## Phase 0.3 — Dashboard and Telemetry

The third phase focuses on building a dashboard that can display system state.

Expected outputs:

- Web or PC dashboard.
- Telemetry panels.
- Command buttons.
- Node status visualization.
- Connection status.
- Error and warning display.

## Phase 0.4 — Simulation Bridge

The fourth phase connects physical or simulated telemetry to a visual simulation.

Expected outputs:

- Virtual node model.
- Node state visualization.
- Basic swarm layout.
- Telemetry-to-simulation mapping.
- Dashboard and simulation connection.

## Phase 0.5 — First Complete Demo

The fifth phase creates the first complete demonstration.

Expected outputs:

- Working hardware chain.
- Working dashboard.
- Working telemetry.
- Working simulation.
- Demo script.
- Demo video.
- Public screenshots.
- Build log.

## Phase 1.0 — Stable Educational Demonstrator

The first major version should be a stable educational demonstrator.

Expected outputs:

- Reproducible setup.
- Clear hardware list.
- Clean firmware.
- Usable dashboard.
- Basic simulation.
- Full documentation.
- Educational explanation.
- Public demo material.
