# MicroBot Labs — Customer Segments and Value Proposition v0.4

Status: customer/value hypothesis  
Created: 2026-05-18  
Hardware validation status: not hardware-validated

## 1. Purpose

This document clarifies who MicroBot Labs could serve and why those users might care.

At the current stage, the most credible users are not industrial robotics buyers. The most credible users are learners, educators, collaborators and reviewers who value a structured robotics learning path.

## 2. Primary customer segment: technical students

Technical students may struggle with fragmented learning. They may learn Arduino separately, web dashboards separately, simulation separately and documentation separately. MicroBot Labs gives them an integrated project where the same concept appears as documentation, firmware, dashboard, simulation and validation evidence.

Customer jobs:

- learn embedded systems;
- understand robotics architecture;
- build a portfolio project;
- understand telemetry and validation;
- prepare for exams, internships or project presentations.

Pains:

- too many disconnected tutorials;
- unclear hardware steps;
- weak documentation;
- no validation discipline;
- hard to present projects professionally.

Gains:

- complete repo;
- clear roadmap;
- visual dashboard;
- staged BOM;
- evidence reports;
- professional narrative.

## 3. Secondary segment: makers

Makers may value MicroBot Labs if it becomes reproducible. They need simple hardware, clear wiring, working firmware and visible feedback.

MicroBot Labs can appeal to makers once the first ESP32 validation and NODE_01 LED validation are complete.

## 4. Secondary segment: educators

Educators may use the project as a teaching tool if it becomes stable enough. The advantage is that it shows not only code, but also architecture, testing, safety, diagrams, business thinking and validation.

Educators need:

- clarity;
- reproducibility;
- low-cost hardware;
- safety;
- student-friendly docs;
- visible demo output.

## 5. Reviewer/collaborator segment

Professors, mentors and technical collaborators are important before customers. Their value is feedback, credibility and direction.

They need to see:

- honest claims;
- real next milestone;
- understandable docs;
- evidence artifacts;
- hardware boundary;
- reasonable scope.

## 6. Value proposition statement

MicroBot Labs helps learners and early-stage robotics builders understand modular robotics through a complete, evidence-based workflow: documentation, ESP32 firmware, dashboard, telemetry, simulation, validation reports and progressive hardware tests.

## 7. Value proposition by segment

| Segment | Main value proposition |
|---|---|
| Students | Learn robotics through a complete technical system, not isolated exercises |
| Makers | Follow a structured ESP32 robotics build with dashboard and validation |
| Educators | Use a staged robotics demonstrator with docs, BOM, diagrams and evidence |
| Professors | Evaluate a serious student-led robotics platform with clear evidence boundaries |
| Collaborators | Join a modular project with defined next milestones |
| Incubators | Review an early robotics education/prototyping concept after hardware evidence exists |

## 8. Positioning statement

MicroBot Labs is not yet a robotics product.

It is a robotics learning and prototyping ecosystem that is becoming reproducible, evidence-based and hardware-ready.
