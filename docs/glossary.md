# MicroBot Labs — Glossary

## MicroBot

A modular robotic or electronic unit used to study distributed behavior, communication, telemetry, and control.

## MicroBot Labs

The experimental project and technical laboratory focused on modular robotics, swarm simulation, embedded systems, dashboards, and educational prototyping.

## Master ESP32

The central microcontroller responsible for receiving commands from the computer and coordinating multiple nodes.

## Node

A physical or simulated unit controlled by the master controller. A node can represent a simple LED module, sensor unit, actuator unit, display module, or future robotic element.

## Telemetry

Data sent from the system to the dashboard or simulation layer. Telemetry may include node status, sensor readings, command responses, battery state, connection state, errors, warnings, or simulated parameters.

## Dashboard

The visual software interface used to monitor and control the system.

## Simulation Layer

The software environment used to visualize nodes, states, communication, swarm behavior, and future robotic interactions.

## Swarm Behavior

The collective behavior of multiple units that interact through local rules, shared states, or coordinated control.

## Firmware

The low-level software running on microcontrollers such as ESP32 boards.

## Prototype v0.1

The first technical demonstrator used to validate the basic MicroBot Labs architecture.
