# MicroBot Labs — v0.4 Purchase Checklist

Created: 2026-05-18  
Purpose: practical checklist before buying v0.4 hardware  
Target: real ESP32 NODE_00_MASTER validation

## 1. Before buying

- [ ] Confirm whether the board connector is USB-C or Micro-USB.
- [ ] Confirm that at least one cable is a data cable, not charge-only.
- [ ] Confirm the board is an ESP32 development board, not only a bare module.
- [ ] Confirm the board exposes GPIO pins.
- [ ] Confirm the board has EN/RESET and BOOT buttons.
- [ ] Confirm the seller includes a pinout or board photo.
- [ ] Confirm delivery time is acceptable.
- [ ] Confirm you are not buying drone parts too early.

## 2. Minimum cart

- [ ] 2x ESP32 development boards.
- [ ] 2x matching USB data cables.
- [ ] 1x breadboard.
- [ ] 1x jumper wires M-M kit.
- [ ] 1x jumper wires M-F/F-F kit.
- [ ] 1x LED assortment.
- [ ] 1x resistor kit with 220 ohm / 330 ohm / 1k / 10k.
- [ ] 1x digital multimeter.
- [ ] 1x USB adapter/hub only if needed for the Mac.

## 3. Budget control

Target budget: 60-100 EUR.

Upper sensible limit for v0.4: 130 EUR.

Stop and re-check the cart if it exceeds 130 EUR, because v0.4 does not need drone hardware, batteries, custom PCBs, motors, sensors or shell parts.

## 4. After delivery

- [ ] Photograph or list components.
- [ ] Do not throw away labels immediately.
- [ ] Check ESP32 board connector type.
- [ ] Connect board with data cable.
- [ ] Run serial port listing command.
- [ ] Upload NODE_00_MASTER firmware.
- [ ] Capture real serial logs.
- [ ] Run validation script.
- [ ] Commit only real evidence.
